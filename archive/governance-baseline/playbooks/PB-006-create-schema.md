# PB-006: Create a Schema

1. Identify the governing ontology concept and specification.
2. Search `meta/SCHEMA_INDEX.yaml` for existing representation ownership.
3. Define stable `$id`, version, required fields, constraints, and compatibility.
4. Do not add meaning absent from the ontology/specification.
5. Add valid, boundary, and invalid examples.
6. Validate composition, references, recursion, and sensitive fields.
7. Update indexes and impact analysis; obtain Schema Steward review.
