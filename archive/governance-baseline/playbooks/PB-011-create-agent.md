# PB-011: Create an Agent

1. Define the QA role, users, outcome, non-goals, consequence class, owner, and Workspace scope.
2. Discover existing capabilities, Skills, rules, knowledge, Tools, Agents, and contracts before adding artifacts.
3. Trace the Agent to accepted product requirements, risks, ADRs, and applicable policies.
4. Create a SPEC-106-conformant Agent Definition with exact inputs, outputs, evidence, limits, permissions, escalation, and compatible Skill/Tool versions.
5. Keep working context ephemeral; route reusable observations only to Knowledge Candidates.
6. Define or select an Evaluation Suite before implementation. Include security, isolation, authority, no-progress, budget, cancellation, and recovery cases.
7. Review GOV-012 G1–G4. Implement only the accepted vertical slice through SPEC-508.
8. Use production and deterministic fake/replay adapters through the same contracts.
9. Run PB-013 and PB-015; retain traceability and gate evidence.
