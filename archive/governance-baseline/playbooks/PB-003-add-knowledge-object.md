# PB-003: Add a Knowledge Object

1. Capture the observation and immutable evidence as a Knowledge Candidate.
2. Validate schema, provenance, Workspace, classification, applicability, and expiry.
3. Search accepted knowledge for duplicates and conflicts.
4. Collect supporting and contradicting evidence.
5. Route to the accountable domain owner and Knowledge Governance.
6. Run QG-08.
7. On approval, create a distinct immutable Knowledge Object version and link the candidate.
8. Preserve rejected or expired candidate history.

Confidence alone never authorizes promotion.
