# PB-012: Create a Skill

1. State one reusable QA purpose and verify it is a procedure, not a Plugin adapter, Tool, product rule, or whole Agent.
2. Discover existing Skills and define positive and negative triggers to prevent overlap.
3. Define inputs, outputs, preconditions, postconditions, normative steps, permitted decisions, evidence, uncertainty, failure, and escalation.
4. Declare knowledge and rule scopes, Tool contracts, side effects, idempotency, compensation, approvals, and Workspace restrictions.
5. Create a SPEC-106 and SPEC-509-conformant definition and schema-valid examples.
6. Create tests for triggers, instruction precedence, contract, Tool use, conflicts, boundaries, portability, replay, failure, and isolation.
7. Pass GOV-012 G1–G4 and an independent review before enabling the Skill in an Agent.
8. Run PB-014 and PB-015; never learn directly from evaluation output.
