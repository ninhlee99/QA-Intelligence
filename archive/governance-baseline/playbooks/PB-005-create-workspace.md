# PB-005: Create a Workspace

1. Assign stable ID, accountable owner, classification, retention, and policy version.
2. Provision isolated storage, indexes, queues, caches, secrets, evidence, and telemetry scopes.
3. Configure membership and least-privileged roles.
4. Validate context issuance and administrative separation.
5. Run positive and cross-Workspace negative tests.
6. Activate only after Security and Workspace owner approval.
7. Record lifecycle and audit evidence.
