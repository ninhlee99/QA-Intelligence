# PB-001: Create a Specification

1. Search `meta/SPEC_INDEX.yaml` and the repository graph for existing ownership.
2. Read Foundation, governance, applicable ADRs, ontology, and upstream specifications.
3. Select the correct number range and one responsibility.
4. Copy `templates/SPEC.md`; set status to `draft` and assign one accountable owner.
5. Define scope, non-goals, contracts, failure behavior, security, Workspace isolation, compatibility, evidence, and acceptance criteria.
6. Update ownership, dependency, traceability, impact, and indexes.
7. Validate metadata and links; run GOV-008 review and GOV-009 gates.
8. Change to `accepted` only after retained approval evidence.

Never create implementation to infer the specification afterward.
