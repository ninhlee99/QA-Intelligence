# PB-004: Create a Plugin

1. Identify an accepted platform interface and missing adapter capability.
2. Define descriptor, permissions, configuration, lifecycle, failure mapping, and evidence policy.
3. Keep provider types and SDKs entirely inside the plugin.
4. Enforce least privilege and SPEC-506 Workspace context.
5. Implement cancellation, timeout, cleanup, health, and version compatibility.
6. Pass SPEC-503 conformance, security, isolation, and provider-substitution tests.
7. Register only after approval; installation does not imply enablement.
