# PB-008: Release

1. Freeze and identify the release manifest.
2. Confirm every included change has valid QG-04 evidence.
3. Run release regression, compatibility, migration, security, and isolation validation.
4. Prepare deployment, rollback, observability, support, and communication.
5. Obtain QG-05 and QG-06 approvals.
6. Deploy progressively and verify QG-07.
7. Retain release-to-runtime provenance and monitor rollback thresholds.
