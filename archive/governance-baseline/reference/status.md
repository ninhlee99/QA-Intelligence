# Canonical Statuses

## Governed Artifacts

`draft → in_review → accepted → deprecated → superseded | archived`

`rejected` is terminal unless a new draft version is created.

Only governed approval may assign `accepted`.

## Knowledge Candidates

`discovered → proposed → validating → promoted | rejected | expired`

Promotion creates or revises a separate Knowledge Object.

## Executions

`planned → queued → preparing → running → collecting_evidence → completed | failed | cancelled | timed_out | blocked`

Product outcome remains distinct from runtime status.
