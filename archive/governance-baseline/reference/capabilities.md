# Capability Catalog

Canonical product capabilities are Discovery, Requirement Intelligence, Requirement Quality Assessment, Business Analysis, Risk Analysis, Test Strategy, Test Design, Test Data, Automation, Execution, Bug Analysis, and Reporting.

Canonical platform capabilities are Knowledge Storage, Ontology Resolution, Rule Evaluation, Controlled Learning, Semantic Analysis, UI Graph Construction, Reasoning, Workflow, Plugin Management, Workspace Isolation, Scheduling, Observability, and Recovery.

Capability names are stable semantic identities. Plugins declare implementation capabilities; they do not create new product meaning implicitly.
