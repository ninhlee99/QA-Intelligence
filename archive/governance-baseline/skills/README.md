# Skills

This is the canonical root for governed QA Intelligence Skill packages.

Each Skill version SHALL contain a schema-valid definition, normative procedure, compatibility notes, ownership, integrity, and Evaluation Suite references. Draft examples belong in `examples/`; executable versions move here only through PB-012 and GOV-012.

A Skill is a reusable QA procedure. It is not a Plugin, Tool adapter, whole Agent, or source of accepted knowledge.
