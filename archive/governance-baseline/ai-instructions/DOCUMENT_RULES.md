# Document Rules

- Search indexes and repository graph before creating an artifact.
- Use canonical templates, IDs, status values, and paths.
- One artifact owns one primary responsibility.
- Summaries reference but do not redefine authority.
- `last_updated` is an ISO date, never a placeholder in reviewed artifacts.
- New artifacts start as `draft`.
- Update ownership, dependencies, traceability, impact, and indexes together.
- Distinguish fact, inference, assumption, candidate, and accepted authority.
