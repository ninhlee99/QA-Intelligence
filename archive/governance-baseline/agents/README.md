# Agents

This is the canonical root for governed QA Intelligence Agent packages.

Each Agent version SHALL contain a schema-valid definition, referenced Prompt content or immutable reference, compatibility notes, ownership, integrity, and links to accepted Evaluation Suites. Draft examples belong in `examples/`; executable versions move here only through PB-011 and GOV-012.

An Agent package does not own accepted knowledge, Tool adapters, product rules, credentials, or evaluation verdicts.
