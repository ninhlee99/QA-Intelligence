# QA Intelligence Ontology

These files are the accepted machine-readable ontology baseline governed by `SPEC-101`.

They define semantic identity and relationships, not persistence layout. Accepted releases SHALL be immutable, versioned, reviewed by the Ontology Steward, and indexed in `meta/ONTOLOGY_INDEX.yaml`.

Structure:

- `entities/core.yaml` — canonical entity types
- `relationships/core.yaml` — canonical predicates and direction
- `enumerations/lifecycle.yaml` — shared lifecycle values
- `constraints/core.yaml` — cross-entity invariants

Workspace-owned instances are not stored in this directory.
