# PB-013: Test an Agent

1. Pin Agent, Skill, Prompt, model, Tool, adapter, rule, knowledge, policy, dataset, environment, and evaluator versions.
2. Validate definitions, authority, Workspace, budgets, suite coverage, critical oracles, and sandbox readiness.
3. Run static and deterministic checks before model-backed trials.
4. Execute isolated normal, negative, boundary, adversarial, Tool, failure, cancellation, recovery, and escalation cases.
5. Repeat non-deterministic trials to the predeclared minimum; retain every attempt.
6. Apply deterministic oracles first, then eligible calibrated Judges, then authorized human review.
7. Separate subject, evaluator, infrastructure, invalid-test, policy-denial, and indeterminate outcomes.
8. Compare the approved baseline and disclose all changed conditions and variance.
9. Produce an immutable recommendation; do not self-approve release or convert findings directly into knowledge.
